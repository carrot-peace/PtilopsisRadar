# 阅读偏好

`config/reader_preferences.json` 中 `exclude_esports: true` 表示电竞内容整体退出 CR 主动提醒与日报 HTML、Telegram、Dashboard 主事件展示。事故、争议、监管等字样不覆盖这项明确偏好；无需摘要或正文即可按已识别的电竞上下文过滤。

CR 在聚类后、呈现与发送前记录 `reader_preference:exclude_esports` 抑制理由。该抑制不会生成高分抑制诊断通知，也不能升级 urgent 绕过夜间静默。延期队列只与当前可发送候选对齐，不会单独发送历史电竞条目。原始采集与内部审计继续保留。

设置为 `false` 可关闭本次新增的整体排除；原有日报常规娱乐/体育/电竞降噪仍按原规则执行。文件不存在时新增排除默认关闭。下个任务会重新读取配置，长期进程也按文件修改时间刷新。可用 `READER_PREFERENCES_PATH` 指定独立配置文件。

实体与赛事识别在 `trendradar/esports.py`。不以“上海”“选手”“冠军”或裸 `vs` 判定电竞；MSI等歧义标识要求竞技上下文。新赛事、队伍、选手或完全不含可识别上下文的隐晦标题仍可能漏认，需要根据实际漏网记录维护识别范围。这个开关表达的是不看电竞的偏好，不是对未知标题实现百分之百语义识别的保证。

具体事件同时检查来源标题；配置词表中的宽泛分类组按标题逐条过滤，不因一个电竞样本删除同组的其他新闻。词表组名从`FREQUENCY_WORDS_PATH`读取，兼容自定义组名。日报折叠示例、背景备注、证据链接和Dashboard页脚也遵守排除；相关计数扣除已排除条目。热榜附录若只保存了截断后的标题列表，仅扣除已知移除数，不把全量计数误改成可见列表长度。
